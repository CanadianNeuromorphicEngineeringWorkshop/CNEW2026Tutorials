Tutorial: Neuromorphic control through the eyes of hybrid systems

This tutorial is based on the paper:
[Petri, Postoyan, Heemels: Rhythmic neuromorphic control of a pendulum: A hybrid systems analysis, IEEE CDC 2025]
(https://ieeexplore.ieee.org/abstract/document/11312586)

This tutorial focuses on the hybrid model and the Matlab simulation of the ryhthmic control of a pendulum presented during the talk. 
The Matlab code, using the Hybrid Equations Toolbox, for the case without adaptation loop can be found in: https://drive.google.com/drive/folders/16FLmSso62cy57GXac_9-gFGkZ3V8huk0?usp=drive_link

Exercise 1: Run the code. How the different choices of parameters affect the simulations?

Exercise 2: To obtain a desired amplitude of the oscillations, adapt the spike's amplitude using the approach presented in the slides (or any other approach you can think about).
How does the hybrid model change?  
How do you need to modify the code to include this adaptation mechanism?
